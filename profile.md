# Профиль — Документация

## Обзор

Система профиля включает: просмотр и редактирование данных пользователя, настройки (уведомления, тема, язык, приватность, безопасность), профили продавцов и арендодателей. Реализована для мобильной и десктопной версий. Требует авторизации.

## Хранилище профиля (userStore)

**Файл:** `src/lib/userStore.ts`

Данные хранятся в `localStorage` под ключом `'auto_toj_user_profile'`.

### Интерфейс данных

```typescript
interface ProfileData {
  name: string
  phone: string
  email: string
  bio: string
  avatar?: string
  banner?: string
}
```

### Методы

| Метод | Описание |
|-------|----------|
| `getProfile()` | Получить данные профиля |
| `saveProfile()` | Сохранить профиль |
| `updateName()` | Обновить имя |
| `updatePhone()` | Обновить телефон |
| `updateCity()` | Обновить город |

**Данные по умолчанию:** Имя: "Алишер Рахимов", телефон: "900123456", город: "Душанбе"

## API аутентификации

**Файл:** `src/services/api/auth.ts`

### Эндпоинты

| Метод | Endpoint | Описание |
|-------|----------|----------|
| POST | `/auth/request` | Запрос SMS-кода |
| POST | `/auth/verify` | Подтверждение кода |
| POST | `/auth/logout` | Выход из аккаунта |

### Типы ответов

```typescript
interface AuthRequestResponse {
  success: boolean
  message: string
}

interface AuthVerifyResponse {
  token: string
  user: {
    id: string
    phone: string
    name: string
    created_at: string
  }
}
```

- Токен сохраняется в `localStorage` через `setAuthToken()`
- Есть mock-реализация `authAPIMock` для разработки

## Навигационная схема

```
MenuPage (мобайл) / DesktopHeader (десктоп)
│
├── Профиль (EditProfilePage / DesktopProfilePage / Drawer)
│   ├── Редактирование имени, email, bio
│   ├── Загрузка аватара и баннера

│   └── Удаление аккаунта

├── Настройки (SettingsPage)
│   ├── Уведомления (toggle-переключатели)
```
